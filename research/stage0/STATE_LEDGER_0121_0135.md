# 双书#121—135连续性账：哪些事真的兑现

说明：只记录源小说内部，历史真实性未单独查考。**书内报告 ≠ 书面许可 ≠ 可支配钱粮 ≠ 当事人已获补偿。** 所有危险行为仅限小说因果/社会责任分析。

| 作品/章节 | 已在场景发生 | 仍不应当作已完成 |
|---|---|---|
| 晚明121—123 | 莱阳一线收尾，京畿警讯传入，船队与人员向新舞台移动 | 莱阳私人与官方所得尚待分清；出航不等于全部抵达和供给稳定 |
| 晚明124—126 | 朝廷、边地和京师家属分别获得部分消息，天津集结并见旅途成本 | 信息是否同步、合作方真正可承担的后勤与居民安置尚未完结 |
| 晚明127—132 | 普通运送者、周少儿、陈瑛及对方家庭构成多条视角线，局部事件转折 | 不等于基层人员已完全自愿、官署已经提供统一认可或对方内部没有新的决定 |
| 晚明133—135 | 前线已出现新的实际成果和人员损失；京师政治信息和官方上报开始转动；地方居民仍受压力 | 伤病补偿、家人账、长期供应和名声后的利益都不能仅凭一场胜利到账 |

| 铁血130—132 | 外部普通人生活仍有动机，县内人员去留和库房短缺，官方身份晋升话题继续 | 离队者已获全部长期保障、名望自动换来法定权利或新的商业利润均未证明 |
| 铁血133—135 | 上级查验此前“战绩”的实物证据，官吏/部属继续评估利益与风险 | 查验一项功绩≠司法、税负、居民社会损失全部清算，更不等于私人经营可无约束 |
